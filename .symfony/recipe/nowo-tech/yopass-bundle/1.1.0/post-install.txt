YopassBundle installed.

1. Flex ships `security_nowo_yopass.yaml`:
   - `^/share` → PUBLIC_ACCESS
   - `^/tools/yopass` → ROLE_ADMIN (align with bundle defaults)

2. Run Doctrine schema update or migration for {table_prefix}secure_shares.

3. Install assets: php bin/console assets:install

4. Prefer short share links (`sharing.default_embed_in_url: false`, Flex when@prod).
   Only enable key-in-URL if you accept proxy/Referer leakage risk.

5. Optional: custom ACL via YopassAccessCheckerInterface and share events
   (see vendor/nowo-tech/yopass-bundle/docs/examples/AccessControl.md).

Public /share/* routes are rate limited per IP when cache.app is configured.
